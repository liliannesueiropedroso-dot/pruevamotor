NEXUS GAME ENGINE — Compilación HTML5
======================================
Proyecto: Mi Proyecto 2D
Plataforma destino: Playgama (Bridge SDK)
Resolución base: 1280 x 720

Archivos generados:
- index.html
- css/style.css
- js/pixi.min.js
- js/portal-sdk.js
- js/nexus-runtime.js
- playgama-bridge-config.json
- data/game.json
- assets/asset_74335bc5d40d_BooxGame_logo_icon_resized.png

Notas de integración:
Incluye playgama-bridge-config.json requerido por el validador de Playgama.

Para probar localmente, sirve esta carpeta con cualquier servidor HTTP estático
(por ejemplo: npx serve . o python3 -m http.server 8080).
